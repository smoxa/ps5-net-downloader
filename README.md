# PS5 Net Downloader 🎮📦

Хоумбрю-пейлоад (ELF) для PlayStation 5, запускающий фоновый демон со встроенным веб-интерфейсом. Позволяет скачивать файлы (включая `.pkg`) напрямую на внутренний накопитель PS5 по прямой HTTP-ссылке через браузер с любого устройства (ПК, смартфон).

---

## ✨ Возможности

* **Встроенный веб-сервер**: Никаких сторонних зависимостей на ПК во время работы — интерфейс открывается прямо с консоли (`http://<IP_PS5>:8080`).
* **Адаптивный интерфейс**: Тёмная тема в стиле PlayStation, отображение прогресса в реальном времени, скорости (MB/s) и общего объема.
* **Потоковая загрузка**: Данные пишутся напрямую на диск чанками, не перегружая оперативную память консоли.
* **Автоматическая облачная сборка (CI/CD)**: Исходный код автоматически компилируется в `.elf` на серверах GitHub Actions через `ps5-payload-sdk`.

## 🚀 Быстрый старт: выгрузка на GitHub

### 1. Подключение вашего репозитория GitHub
Создайте новый пустой репозиторий на [GitHub.com/new](https://github.com/new) (например, `ps5-net-downloader`).

В терминале PowerShell в папке проекта выполните:
```powershell
git remote add origin https://github.com/<ваш-логин>/<имя-репозитория>.git
```

### 2. Автоматическая отправка изменений
Для отправки кода на GitHub запустите скрипт:
```powershell
.\sync.ps1 "Первоначальный коммит"
```
Скрипт сам добавит измененные файлы, создаст коммит и выполнит `git push`.

### 3. Получение готового `.elf`
1. Откройте ваш репозиторий на GitHub.
2. Перейдите во вкладку **Actions**.
3. Откройте последний завершённый запуск воркфлоу **Build PS5 ELF Payload**.
4. В блоке **Artifacts** скачайте архив с готовым `ps5-net-downloader.elf`.

## 🕹️ Использование на PS5

### Шаг 1: Запуск эксплойта и ELF Loader
1. Запустите эксплойт на вашей PS5 (через браузер WebKit или бэкдор-пейлоад).
2. Убедитесь, что активен **ELF Loader** (обычно слушает порт `9020` или `9021`).

### Шаг 2: Отправка ELF на консоль
Отправьте скомпилированный `.elf` на IP-адрес вашей PS5.

**Через PowerShell:**
```powershell
$ps5Ip = "192.168.1.50" # Замените на IP вашей PS5
$port = 9020
$bytes = [System.IO.File]::ReadAllBytes("ps5-net-downloader.elf")
$client = New-Object System.Net.Sockets.TcpClient($ps5Ip, $port)
$stream = $client.GetStream()
$stream.Write($bytes, 0, $bytes.Length)
$stream.Close()
$client.Close()
```

*(или через Netcat / утилиты отправки пейлоадов вроде PS5 Payload Sender).*

### Шаг 3: Загрузка файлов
1. На компьютере или телефоне откройте браузер и введите:
   ```
   http://<IP_ВАШЕЙ_PS5>:8080
   ```
2. Вставьте прямую ссылку на файл (HTTP/HTTPS) и нажмите **«Начать загрузку на PS5»**.
3. Файл сохранится в каталог `/data/pkg/` (или указанную вами папку).
